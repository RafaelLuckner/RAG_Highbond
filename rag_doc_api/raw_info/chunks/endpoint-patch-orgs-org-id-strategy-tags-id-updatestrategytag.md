## Strategy

You can use the Strategy app to identify, assess, and monitor strategic risks.

Learn more.

### `PATCH /orgs/{org_id}/strategy_tags/{id}` — Update a Tag

- **operationId:** `updateStrategyTag`
- **Domínio(s):** Strategy

Make changes to a tag, including updating the tag's name or linking it to segments.
